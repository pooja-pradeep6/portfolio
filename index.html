Toxic comment classification with explainability

Python · scikit-learn · TF-IDF · LIME · Hugging Face

Classifies online comments as Toxic or Clean and uses LIME to show which words drove each prediction.

  • Used 30,000 Civil Comments (92.18% clean, 7.82% toxic), split 80/20 and stratified.
  • Logistic Regression with balanced class weights reached 87% accuracy, with toxic recall 0.58 and F1 0.42.
  • Reported why accuracy alone misleads on imbalanced data and suggested BERT, n-grams and a human review stage.
