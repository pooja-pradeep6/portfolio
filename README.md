# Pooja Pradeep: Portfolio

Static site (HTML, CSS, JavaScript). No build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy free
Drag the folder into Netlify Drop, or push it to a GitHub repo named `<username>.github.io` and enable GitHub Pages.

## Edit
- Text and projects: `index.html`
- Colours and fonts: variables at the top of `style.css`
- Demo word weights: `WEIGHTS` in `script.js`
- Photo: replace `assets/pooja.jpg`
